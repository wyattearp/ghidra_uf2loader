UF2 Loader

The UF2 Loader extension allows Ghidra to import Microsoft's USB Flashing Format (UF2) files.

Overview

UF2 is a file format designed for flashing microcontrollers over MSC (Mass Storage Class). It consists of 512-byte blocks, each containing a header, 256 or 476 bytes of data, and magic numbers.

This loader automatically:

  • Identifies the target board/architecture using the Family ID.
  • Maps data blocks to their target addresses in memory.
  • Merges contiguous blocks into single memory segments for easier analysis.
  • Uses FileBytes to maintain a backlink to the original file data.

Supported Architectures

The loader currently supports the following architectures based on Family ID:

  • ARM Cortex (RP2040, STM32, SAMD, etc.)
  • Xtensa (ESP32, ESP8266)
  • RISC-V (ESP32-C3)
  • AVR8 (ATmega32)
